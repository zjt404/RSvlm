# RSvlm · 遥感视觉语言模型的监督微调与强化学习

基于 **Qwen3-VL-4B**，构建遥感视觉问答、计数、单目标定位、空间关系判断及条件关系全框定位系统。采用 **LoRA SFT → GRPO** 训练流程，将自然语言条件映射为结构化目标框集合，以固定测试集评估任务性能和通用能力保留情况。

## 方法

- **多任务监督微调**：使用 VRSBench、DIOR 构建问答、计数、定位与空间关系数据，结合 ReCon1M 关系标注学习条件全框输出。
- **混合密度训练**：GRPO 使用 2,000 条关系样本，按 1–4、5–10、11+ 个目标分配 800 / 600 / 600 条；另加入 500 条通用任务回放，四类任务各 125 条。
- **标注感知奖励**：联合一对一框匹配、Precision、Recall、F1、匹配 IoU、计数一致性与格式奖励，对干扰目标、重复框、无效框及未知预测施加不同惩罚，对不确定标注采用忽略处理。
- **统一评测**：固定图像、问题、生成设置及评分器；全框任务使用 IoU≥0.5 的一对一匹配，通用任务分别报告各自指标。

## 实验结果

**Baseline** 为未进行本项目微调的基础模型；**SFT** 为最终关系专项监督模型；**GRPO** 为从该 SFT 继续训练的最终模型。实际检查点与结果来源见 [实验协议](docs/experiment_protocol.md)。百分数以 % 展示，计数误差以目标数量为单位。

## 快速使用

需要 Python 3.10–3.12、兼容的 PyTorch/CUDA 环境，以及单独准备的基础模型和适配器。

```bash
pip install -e '.[train,app,dev]'
python scripts/chat_v8.py \
  --model /path/to/Qwen3-VL-4B \
  --adapter /path/to/checkpoint-625 \
  --image /path/to/image.jpg \
  --question "找出停车场内所有停放的车辆" --boxes
```

全框输出格式示例：

```json
{"count":2,"selected_bboxes":[[125,340,210,430],[620,510,690,580]]}
```

框使用归一化至 0–1000 的 `[x1,y1,x2,y2]` 坐标。命令行返回坐标文本。普通问答、计数、单框定位、空间关系分别使用 `--task vqa`、`--task count`、`--task grounding`、`--task spatial`。
