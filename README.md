# Qwen3-VL 遥感多任务微调与关系全框定位

基于 Qwen3-VL-4B，使用 LoRA SFT 与 GRPO 完成遥感问答、计数、定位和空间关系任务。最终 v8 从 v6 SFT 权重继续训练，使用混合密度关系样本及通用任务回放。

## 已完成实验

ReCon1M 条件关系全框定位：固定 2,666 条测试样本，IoU=0.5 下的一对一匹配。以下 F1 是条件全框定位指标，不是目标检测 mAP。

| 模型 | Precision | Recall | F1 | 计数 MAE |
|---|---:|---:|---:|---:|
| v6 SFT | 45.70% | 45.05% | 45.37% | 2.319 |
| v7 GRPO | 37.95% | 50.58% | 43.36% | 2.837 |
| v8 GRPO | 46.32% | 45.94% | 46.13% | 2.289 |

4,000 条固定通用测试集上的 v8 结果：VQA 准确率 69.00%，计数精确率 74.70%、MAE 0.951，单框定位 Acc@0.5 74.20%、mean IoU 0.6487，空间关系准确率 66.80%，JSON 有效率 100%。这些点估计与 v6 接近；尚未进行统计非劣效检验，不能据此宣称严格证明能力未退化。

结果来自已完成的实验日志；本仓库不包含数据集、模型权重和原始预测文件。整体 F1 较 v6 提升 0.76 个百分点，尚未进行多随机种子或显著性检验。实际测试仍存在漏检、重复框和自然语言提示泛化不足。

## 使用说明

安装、数据构建及服务启动见 [项目说明](PROJECT_README.md)。其中早期实验配置属于历史方案，最终训练入口为 `scripts/train_grpo_v8_mixed.sh`。

单图测试（需先配置模型及适配器路径并安装依赖）：

```bash
python scripts/chat_v8.py --model /path/to/Qwen3-VL-4B --adapter /path/to/checkpoint-625 --image /path/to/image.jpg --question "找出停车场内所有停放的车辆" --boxes
```

普通视觉问答使用 `--task vqa`；计数、单框定位、空间关系分别使用 `--task count`、`--task grounding`、`--task spatial`。不传任务参数时直接使用用户问题。`--boxes` 返回归一化到 0–1000 的坐标文本，当前该命令行入口不会自动在图上画框。

训练脚本中的服务器路径需要按实际环境调整。模型和各数据集的获取与使用须遵守其各自的许可。
